# Skitrack (web)

Recherche de séjour ski : totaux de séjour, mix de pistes, distance au front de neige **mesurée** (GPS de l’annonce → station). Rien n’est inventé.

Sources live : **Airbnb**, **Booking**, **Abritel**, **Gîtes de France**.

```
npm install
npm run dev
```

Branche `web` du dépôt [BalderLeBrave/Skitrack](https://github.com/BalderLeBrave/Skitrack) — l’app Electron reste sur `master`.
