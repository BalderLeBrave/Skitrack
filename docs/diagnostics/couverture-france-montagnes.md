## Note sur le moteur local

La base OpenSkiMap importée par le moteur (`npm run sidecar:stats`) porte
**277 domaines**, dont 259 exploitables. Confrontée au catalogue, elle en
couvre **164 sur 232** — contre les chiffres ci-dessus pour le seul fichier
livré. Démarrer le moteur augmente donc nettement la liste sans rien changer
au modèle : le filtre du catalogue s’applique de la même façon aux deux
sources.
